## 1. Executive summary (Gemini용 요약)

제미나이 초안은 **독창성·수익모델·GTM 단계**가 잘 잡혀 있음. 2차에서 가장 큰 보완은:

1. **「네트워크 연결 시 육상 클라우드 자동 암호화 동기화」** → 실제 선박 운영은 **ZIP Export/Import만**(오프라인 우선). 이를 **차별점(위성비·보안·데이터 주권·실선 성공률)**으로 재서술.
2. **Class/PSC 「국제 공인 규격 즉시」** → **결함·작업허가 케이스, Export ZIP/HTML, Class·PSC 체크리스트 연계** 수준으로 구체화.
3. **대중성:** 엑셀·Off-hire·중소 선사 키워드, IMPA·Maritime Toolkit PLG, PoC·체크리스트로 **실현 가능성** 강화.
4. **Q8에 4번째 개선:** 기술 스토리 정교화(오프라인+ZIP).

## 3. 심사 기준별 보완 포인트

### 3.1 독창성

- **3-Way 자동 연동:** 정비 저장 시 소모 부품 반영 + Chief 확인 단계 재고 규칙·이중 차감 방지.
- **오프라인–육상 하이브리드:** 「항상 클라우드 PMS는 원양에서 실패한다」 프레이밍 → ZIP 표준 패킷, 선박 ID·부서 검증.
- **Captain Hub:** 갑판·기관 → 선장 → 육상 relay, 부서별 RBAC.
- **법정·검사 대응:** Defect / Work Permit 케이스, Export 시 검사 대응 리포트·패키지 (Class·PSC 보고 체크 필드).
- **IMPA + Maritime Toolkit:** SEO·무료 도구 → 본선 PMS·재고는 유료 SaaS 퍼널.

### 3.2 대중성

- Q2: **Off-hire 1일 손실** 또는 **중복 발주** 등 숫자 1개 + **현장 일화** 1개.
- 타깃 명확화: **10~50척, IT 전담 없는 국내·아시아 중소 선사·SM**.
- 비유: 과한 「배달의민족」 대신 **「중소 선사의 엑셀을 대체하는, 선원도 쓰는 쉬운 UX」**.

### 3.3 실현 가능성

- MVP 완료 항목: PMS+SPARE, Defect/Permit, ZIP sync, Electron SKU, pilot 체크리스트.
- PoC: 협력 1~4척, **성공 지표**(ZIP 라운드트립, NPS, 재고 불일치 건수) — Q4-1·Q8 동일 숫자.
- 경쟁 한 줄: 고가 외산·대형 선사 PMS vs **중소·저비용·오프라인 우선**.
- 리스크: 디지털 전환 → 3클릭·데모·Freemium; 데이터 → ZIP 백업·선박 ID 검증.
- ISM **유지보수 기록·추적성** (감사 언어, 짧게).

**교체·삽입 블록 — 「검사·감사 대응」**

> 결함·작업허가 이력을 케이스 단위로 관리하고, Export 시 검사 대응용 리포트·패키지를 생성해 Class·PSC 대비 밤샘 서류 작업을 줄입니다.
