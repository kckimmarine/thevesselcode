## 1. 영상은 어디에서 만들나? (제작 환경 가이드)

### 권장: **본인 Windows PC 한 대에서 전부 완성**

| 구분 | 어디서 | 무엇으로 | 비고 |
|------|--------|----------|------|
| **2막 실화면 (30초)** | **본인 PC** | OBS Studio(권장) 또는 Windows `Win + Alt + R` (Xbox Game Bar) | TVC는 **로컬 서버**로 돌리는 것이 가장 안정적 |
| **1막 애니 (60초)** | **본인 PC** | **CapCut 데스크톱** 또는 **Canva(영상)** | 템플릿·스티커·TTS |
| **합성·자막·BGM** | **본인 PC** | **CapCut** | 1막+2막 타임라인 한 프로젝트 |
| **제출** | **유튜브** | 브라우저 → 업로드 → **일부 공개(Unlisted)** | Q5에 URL만 기재 |

**실화면을 찍을 때 TVC-PMS 띄우는 방법 (택 1):**

1. **개발/데모 (권장)** — 프로젝트 폴더에서:
   ```bash
   npm start
   ```
   브라우저: `http://localhost:3000`  
   (`file://`로 `index.html` 직접 열기 **금지** — 저장소·IndexedDB 프로필이 달라짐)

2. **이미 배포된 사이트** — 선박 PMS가 웹 데모로 공개된 URL이 있으면 동일 동선으로 녹화 (없으면 1번)

3. **Electron 설치형** — 시범용 `TVC-PMS-VESSEL_ENGINE` Setup이 있으면 Engine SKU로 녹화 가능 (메뉴 경로는 웹과 동일 계열)

**애니 소스(선박·바다 일러스트):**

- CapCut / Canva **내장 스티커·템플릿** (저작권 안전)
- 직접 촬영 불필요
- AI 영상(선박·바다)은 **5초 이하 B-roll**만 — 왜곡·환각 주의

**클라우드만으로 만들기:**  
Cursor Cloud VM은 **심사용 영상 제작 공간이 아님**. 녹화·CapCut·유튜브 업로드는 **창업자 PC**에서 하는 것이 맞습니다.

**소요 시간 (1~2시간 플랜):** 실화면 리허설 15분 → 녹화 15분 → CapCut 1막 30분 → TTS·합성 20분 → 렌더·유튜브 10분

## 2. Q5 90초 하이브리드 콘티 (애니 60초 + 실화면 30초)

- **톤:** 딥 네이비 `#0a101e` · 모던 엔지니어링 인포그래픽 + 실화면  
- **도구:** CapCut/Canva(1막) + OBS/Game Bar(2막)

### [1막] 애니메이션 (0:00 ~ 1:00) — 독창성 & 대중성

#### Scene 1 (0:00~0:15) 바다의 거대한 공장과 아날로그의 고통

- **화면:** 바다 위 화물선 → 기관실 단면. 엑셀·수기 장부 붉게 깜빡임 → Off-hire 경고
- **자막:** `바다 위 거대한 복합 플랜트. 정비와 부품 관리는 여전히 엑셀과 수기입니다.`
- **내레이션:** `하루 수천만 원의 손실을 부르는 운항 지연과 중복 발주. IT 전담 없는 10~50척 중소 선단의 고질적인 문제였습니다.`

#### Scene 2 (0:15~0:35) 오프라인 · 3스테이션 · ZIP

- **화면:** 선박 내부 **[ECR 기관] · [CCR 갑판]** → **[Captain Hub]** 취합 → 네트워크 차단(오프라인) → **ZIP 패킷** → 이메일·USB·메신저 → **육상 HQ**
- **주의:** 기관=**ECR**, 갑판=**CCR** (호칭 바꿔 쓰지 않기)
- **자막:** `선박 100% 오프라인 완결 | ECR·CCR → Captain Hub → 표준 ZIP → 육상 HQ`
- **내레이션:** `위성 통신이 끊겨도 바다 위에서 작동합니다. 부서별 정비는 선장 Hub를 거쳐 가벼운 ZIP 패킷으로 육상과 맞춥니다.`

#### Scene 3 (0:35~0:48) 육상 관제 · 정비–재고 연동

- **화면:** 육상 모니터 **TVC-SM** 스타일 대시보드(일러스트 또는 `/sm` 캡처 삽입). 정비 보고와 **SPARE** 재고 카운트 연동 모션
- **자막:** `정비 보고와 SPARE 재고 연동 (중복 차감 방지)`
- **내레이션:** `수억 원대 외산 ERP 대신, 정비 한 번이면 부품 재고까지 같은 흐름으로 맞춥니다.`

#### Scene 4 (0:48~1:00) PLG · Maritime Toolkit

- **화면:** thevesselcode.com · **1.5만 건+ IMPA** · 플랜지·벙커 등 툴킷
- **자막:** `전 세계 실무자가 찾는 Maritime Toolkit → 유료 PMS 구독`
- **내레이션:** `1.5만 개 표준 선용품과 실무 도구로 트래픽을 모으고, 본선 재고·PMS는 B2B SaaS로 연결합니다.`

### [2막] 실제 TVC-PMS (1:00 ~ 1:30) — 실현 가능성

#### Scene 5 (1:00~1:18) PMS · SPARE 연동

- **화면 (실제 녹화):** `engineer` / `0000` / **Engine** → PMS → Make Report → 사용 부품 입력 → **Save** → **SPARE** 탭에서 재고 감소  
  (Work Report만으로 안 보이면: SPARE → **Make Consumption Report** → Cos=1 → Save)
- **자막:** `실제 TVC-PMS: 정비 보고 저장 → SPARE 재고 연동`
- **내레이션:** `지금 보시는 것은 이미 동작하는 MVP입니다. 정비를 기록하면 예비 부품 재고까지 맞춥니다.`

#### Scene 6 (1:18~1:25) ZIP Export · Defect

- **화면 (실제 녹화):** **Menu → Data Export & Import** → Export → ZIP 저장  
  Defect 케이스 → 검사 대응 **리포트·Export** 화면 (「우측 상단 Export ZIP」버튼 **없음**)
- **자막:** `ZIP 패킷 동기화 & 선급·PSC 검사 대응 리포트`
- **내레이션:** `선박과 육상은 ZIP으로 맞추고, 결함·검사 대응 패키지를 바로 꺼냅니다.`

#### Scene 7 (1:25~1:30) CTA

- **화면:** THE VESSEL CODE 로고 + `https://thevesselcode.com/`
- **자막:** `1급 기관사의 노하우를 코드로 | THE VESSEL CODE`
- **내레이션:** `바다의 비효율을 줄이는 스마트 선박관리, 더베슬코드입니다.`

## 3. 실화면 10클릭 동선 (녹화 체크리스트)

1. `npm start` → `http://localhost:3000`
2. `engineer` / `0000` / Engine

10. 엔딩 URL

**녹화 설정:** 1280×720 또는 1920×1080, 40초 원본 → 2막에서 30초 사용
